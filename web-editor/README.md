# Pagecraft — 로컬 웹 문서 에디터

`index.html`을 Chrome 또는 Edge에서 여세요. 설치나 외부 라이브러리가 필요 없습니다.

- 문서를 클릭해 바로 입력·수정·삭제합니다.
- 제목, 굵게, 기울임, 밑줄, 색상, 정렬, 목록, 링크, 표를 지원합니다.
- 이미지 버튼, 드래그 앤 드롭, 클립보드 붙여넣기로 사진을 넣습니다.
- 이미지를 클릭하면 오른쪽에서 너비와 설명을 수정하거나 삭제할 수 있습니다.
- 미리보기는 저장되는 페이지의 모습을 보여줍니다.
- **폴더에 저장 / Ctrl+S**: 폴더를 선택하면 `문서 이름.html`과 `img/`에 저장합니다. 같은 폴더에 같은 문서 이름으로 다시 저장하면 기존 파일을 덮어씁니다. 이 에디터의 저장용으로 빈 폴더를 선택하는 것이 좋습니다. 기존의 사용하지 않는 이미지 파일은 자동 삭제하지 않습니다.
- **ZIP 다운로드**: 모든 브라우저에서 HTML과 `img/`를 ZIP으로 다운로드합니다. 압축을 푼 뒤 HTML을 여세요.
- **폴더 열기**: 저장한 HTML과 이미지를 함께 불러와 다시 편집합니다. 여러 HTML이 있으면 파일명을 선택합니다.
- **열기**: HTML 단독 불러오기입니다. 별도 이미지가 있는 문서는 폴더 열기를 사용하세요.
- 문서는 IndexedDB에 임시 저장되고 다음 실행 시 복원됩니다. 임시 저장은 HTML 파일 저장과 별개입니다. 브라우저 데이터 삭제 시 임시 문서도 삭제됩니다.

폴더 접근 기능은 Chrome·Edge와 보안 컨텍스트에서 지원합니다. 브라우저에서 로컬 파일의 폴더 접근을 제한한다면 ZIP 다운로드를 쓰거나, 이 디렉터리를 로컬 웹 서버에서 열어 사용하세요.

외부 HTML은 텍스트와 기본 서식 위주로 가져옵니다. 스크립트·폼·외부 스타일·외부 이미지·임의 웹사이트 레이아웃은 가져오지 않습니다. 이미지 형식: PNG, JPEG, WebP, GIF, AVIF, BMP (개당 25MB 이하). 모든 문서와 이미지는 PC 내에서 처리되며 서버로 전송하지 않습니다.
