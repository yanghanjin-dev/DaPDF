# DaPDF Viewer & Editor v0.1.8

Rust + Win32 GDI + PDFium 기반 Windows x64 PDF 뷰어 및 실험적 편집 도구입니다.

## 실행

Windows x64에서 다음 두 방식으로 실행할 수 있습니다.

- 설치형: `DaPDF-v0.1.8-win-x64-setup.exe`를 실행하고 UAC 관리자 권한 요청을 승인합니다. 기본 경로는 `C:\Program Files\DaPDF`이며 모든 사용자에게 설치됩니다. 시작 메뉴 바로가기가 생성되고, 바탕화면 바로가기와 PDF 연결 프로그램 등록은 선택할 수 있습니다.
- 포터블: `DaPDF-v0.1.8-win-x64.zip`을 풀고 `DaPDF.exe`를 실행합니다. 같은 폴더의 `pdfium.dll`, 라이선스 파일과 `licenses/` 폴더를 함께 유지하세요.

제거는 Windows **설정 → 앱 → 설치된 앱 → DaPDF → 제거**, 또는 시작 메뉴의 **DaPDF 제거**를 사용합니다. 제거에도 관리자 권한이 필요합니다. 설치한 프로그램 파일·바로가기·등록 정보가 제거되며, 사용자가 별도로 만든 PDF와 문서는 보존됩니다. PDF 기본 앱은 자동 변경하지 않습니다. 포터블 버전은 설치 목록에 등록되지 않습니다.

상단 열기 버튼 또는 O 키로 PDF를 열 수 있습니다. 파일 경로를 실행 인수로 지정하거나 창에 PDF를 드롭할 수도 있습니다. 편집 전 원본 사본을 보관하세요. Ctrl+S는 현재 파일을 덮어씁니다.

## 제공 기능

- 보기: 확대·축소, 너비 맞춤, 단면·양면, 화면 회전, 다크 모드, 전체 화면.
- 탐색: 기본 왼쪽 썸네일 패널, 페이지 이동, 내부 페이지 링크와 외부 URI 링크. 목차 UI는 비활성화되어 있습니다.
- 검색: 썸네일 오른쪽의 검색 탭에서 한글 조합 중인 글자를 바로 표시하며 Enter로 검색을 시작합니다. 이후 Enter마다 다음 결과로 이동하고 문서 전체 총 검색 건수와 현재 순서를 표시합니다. F 또는 Ctrl+F로 검색 탭을 열고 F3·Shift+F3으로 결과를 이동합니다.
- 텍스트: 검색, 마우스 드래그 부분 선택, 클립보드 복사, 우클릭 복사·강조·검색 메뉴.
- PDF 변경: 텍스트 객체 추가, 빈 페이지 삽입·삭제, 다른 PDF 삽입·병합, 현재 페이지 추출, CropBox 조정, 저장 및 PDF 1.4·1.7 지정 저장.
- 내보내기: 현재 페이지 BMP, 추출 텍스트 기반 TXT·HTML·RTF·CSV.
- 실험 기능: 화면 주석·연필·마스킹, 서명 이미지·도장, 자체 양식 편집, 일부 항목 평면화.

## 현재 제한 사항

- 강조·영역 강조·밑줄·취소선·연필은 PDF 주석으로 저장하고 다시 편집할 수 있습니다. 자체 양식·서명 이미지 등 나머지 오버레이와 워터마크·배경색은 일반 저장으로 보존되지 않습니다.
- 평면화는 현재 페이지의 마스킹 사각형, 양식 텍스트·드롭다운, 서명 이미지만 PDF 객체로 반영합니다. 모든 주석·양식을 저장하는 기능은 아닙니다. 반복 실행하면 객체가 중복될 수 있습니다.
- 검은색 마스킹은 아래의 원문을 제거하지 않습니다. 기밀 정보 삭제 용도로 사용하지 마세요.
- 서명·도장은 이미지 표시이며 인증서 기반 디지털 서명이 아닙니다. 자체 양식은 표준 PDF AcroForm 편집이 아닙니다.
- Windows 인쇄 작업 전송을 구현했습니다. 실제 프린터 출력은 별도 수동 확인이 필요합니다.
- RTF·CSV 변환과 표 인식은 추출 텍스트 기반입니다. 원래 Word·Excel 레이아웃을 보존하지 않습니다. 텍스트 중심 DOCX 내보내기와 Windows OCR을 제공하며 OCR 언어 팩이 필요합니다.
- 기본 글꼴로 텍스트를 삽입하므로 한글 등 비라틴 문자의 삽입·표시는 추가 검증이 필요합니다.
- 암호 문서 입력은 제공하지 않습니다. 편집 취소·다시 실행과 종료 시 미저장 변경 확인을 지원합니다.

## 주요 단축키

| 키 | 동작 |
|---|---|
| O / Ctrl+O | 열기 |
| Ctrl+S | 현재 PDF 저장 |
| C / Ctrl+C | 선택 텍스트 복사, 선택 없으면 현재 페이지 텍스트 복사 |
| F / F3 / Shift+F3 | 검색 / 다음 결과 / 이전 결과 |
| G | 페이지 번호 이동 |
| 방향키 좌우 / PageUp·PageDown | 이전·다음 페이지 |
| + / - / W | 확대 / 축소 / 너비 맞춤 |
| D / R / V / F11 | 양면 / 화면 회전 / 다크 모드 / 전체 화면 |
| H / F1 | 도움말 |

## 개발 및 배포

Rust Windows x64 도구 체인과 포함된 PDFium 라이브러리가 필요합니다.

```powershell
$env:PATH = "$PWD\vendor\bin;$env:PATH"
cargo test --offline
cargo run --release --offline -- "test-한글.pdf"
.\release.ps1
```

배포 스크립트는 `VERSION`과 `Cargo.toml`의 일치를 검사하고 회귀 테스트, 릴리스 빌드, 패키징을 수행합니다. `releases/`에 ZIP·설치 EXE와 각각의 SHA256 파일을 생성하며 GitHub에 업로드하지 않습니다. 설치 EXE 제작에는 Inno Setup 컴파일러가 필요합니다. `-SkipInstaller`로 포터블 ZIP만 만들 수 있습니다. 기존 버전 번호를 변경하거나 기존 배포 폴더를 삭제하지 않습니다. 설치 구성과 테스트 방법은 [설치 프로그램 문서](installer/README.md)를 확인하세요.

검증 범위와 결과는 [v0.1.8 릴리스 노트](releases/notes-v0.1.8.md)를 확인하세요.
