# DaPDF Viewer (v0.0.2)

**DaPDF**는 **Rust + Win32 GDI + PDFium (C FFI)** 기반으로 구축된 초경량·고속 네이티브 Windows PDF 뷰어입니다. 무거운 외부 GUI 프레임워크 없이 순수 Windows API(windows-sys)와 Google PDFium 렌더링 엔진을 직접 결합하여 빠른 구동 속도와 메모리 안전성을 제공합니다.

---

## 주요 기능 (Features)

* **고속 네이티브 렌더링:** 32-bit Top-Down BGRA 비트맵 직접 출력 및 ClearType(FPDF_LCD_TEXT) 텍스트 가독성 최적화
* **한글 파일 경로 완벽 지원:** FPDF_LoadMemDocument 기반 메모리 로더 적용으로 한글/특수문자 경로 완벽 대응
* **다양한 열람 레이아웃:**
  * **창 너비 맞춤 (W):** 가로 폭 기준 자동 확대 및 상하 연속 스크롤 독서 모드
  * **2페이지 양면 보기 (D):** 좌·우 페이지 나란히 보기(Spread View) 및 2페이지 단위 이동
  * **야간 다크 모드 (V / N):** 눈의 피로를 줄이는 소프트 다크 색상 반전 필터
  * **페이지 회전 (R / Shift+R):** 시계 / 반시계 방향 90도 단위 회전
  * **전체 화면 (F11):** 다중 모니터 해상도 자동 대응 전체 화면 모드
* **문서 전체 키워드 검색 (F):** 실시간 검색어 입력, 반투명 하이라이트 오버레이 표시, 페이지 간 자동 순회 점프 (N / F3)
* **북마크(목차) 사이드바 (B):** 문서 내 계층형 목차 트리 추출, 좌측 사이드바 클릭 이동 및 이전/다음 챕터 점프 ([ / ])
* **편의 유틸리티:**
  * 원하는 페이지 번호 직접 입력 이동 (G)
  * 현재 렌더링된 페이지를 고해상도 BMP 이미지로 저장 (S)
  * 현재 페이지 텍스트 추출 및 클립보드 복사 (C)
  * 문서 메타데이터(제목, 저자, 생성일, 페이지 제원 pt/mm) 조회 (I)
  * 전체 단축키 및 조작 도움말 팝업 (H / F1)

## 단축키 및 조작법 (Shortcuts)

| 분류 | 단축키 / 마우스 조작 | 설명 |
| :--- | :--- | :--- |
| **파일 열기** | O (Ctrl+O) / 드래그 앤 드롭 | PDF 파일 열기 대화상자 호출 또는 창에 파일 드롭 |
| **이미지 저장** | S (Ctrl+S) | 현재 렌더링된 화면을 BMP 이미지 파일로 저장 |
| **텍스트 복사** | C (Ctrl+C) | 현재 페이지의 텍스트를 추출하여 클립보드에 복사 |
| **문서 정보 / 도움말** | I / H (F1) | 문서 메타데이터 속성 확인 / 전체 단축키 도움말 팝업 |
| **페이지 이동** | 마우스 휠, 방향키, PgUp/PgDn | 이전/다음 페이지 이동 (폭 맞춤 시 상하 스크롤 후 이동) |
| **페이지 번호 점프** | G (Ctrl+G) | 페이지 번호 직접 입력 후 Enter로 즉시 이동 |
| **확대 / 축소 / 이동** | Ctrl+휠, +/- / 좌클릭 드래그 | 화면 확대·축소 (25%~500%) / 화면 자유 이동 (Pan) |
| **뷰 초기화** | 0 | 배율(100%), 회전(0도), 화면 위치 초기화 |
| **너비 맞춤 / 양면 보기** | W / D | 창 너비 맞춤(Fit-to-Width) / 2페이지 양면 보기 토글 |
| **야간 다크 모드** | V (또는 검색어 없을 때 N) | 야간 독서용 다크 모드(색상 반전) 토글 |
| **페이지 회전 / 전체화면** | R, Shift+R / F11 | 시계/반시계 90도 회전 / 전체 화면 전환 |
| **목차 사이드바** | B / [ , ] | 좌측 북마크 패널 열기·닫기 (클릭 이동) / 이전·다음 챕터 이동 |
| **문서 전체 검색** | F (Ctrl+F) | 실시간 키워드 검색 모드 진입 (Enter: 확정, ESC: 취소) |
| **검색 결과 순회** | N (F3) / Shift+N (Shift+F3) | 다음 / 이전 검색 결과 하이라이트로 이동 (전체 페이지 순회) |
| **취소 / 종료** | ESC | 입력·검색 해제 -> 전체화면 복원 -> 프로그램 종료 |

## 프로젝트 구조 및 빌드 방법 (Build)

* **Cargo.toml:** Rust 패키지 및 의존성 설정 (windows-sys)
* **build.rs:** vendor/lib/pdfium.dll.lib 자동 링크 및 pdfium.dll 복사 스크립트
* **release.ps1:** 릴리스 패키징 자동화 스크립트
* **VERSION:** 현재 프로젝트 버전 (0.0.2)
* **src/main.rs:** Win32 GUI 및 PDFium FFI 메인 소스 코드
* **vendor/:** PDFium 바이너리(pdfium.dll), 헤더(include), 라이브러리(lib)

### 빌드 명령어
    cargo run
    cargo build --release
