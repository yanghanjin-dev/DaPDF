# DaPDF Viewer & Editor (v0.0.5)

**DaPDF**는 **Rust + Win32 GDI + PDFium (C FFI)** 기반으로 구축된 초경량·고속 네이티브 Windows PDF 통합 솔루션입니다. 무거운 외부 프레임워크 없이 순수 Windows API(windows-sys)와 Google PDFium 엔진을 결합하여, 알PDF 4.0 매뉴얼의 10대 핵심 메뉴 체계와 비주얼 도구 모음(Toolbar), 하단 상태 표시줄(Status Bar), 좌측 목차·페이지 썸네일 패널을 제공합니다.

---

## 주요 화면 구성 및 기능 (v0.0.5)

### 1. 좌측 사이드바 패널 ([📑 목차] / [🖼 썸네일] 전환 탭)
* **목차(Bookmarks) 탭:** 문서의 계층형 목차 트리 표시, 클릭 점프 및 마우스 휠 스크롤을 지원합니다.
* **페이지 썸네일 미리보기 탭:** 각 페이지의 축소판(Thumbnail)을 지연 렌더링 및 캐싱(`HashMap`)하여 대용량 문서도 끊김 없이 스크롤하며 클릭 한 번으로 원하는 페이지로 즉시 이동할 수 있습니다.

### 2. 상단 비주얼 도구 모음 (Quick Toolbar)
* 자주 사용하는 17가지 핵심 도구(열기, 저장, 축소, 확대, 폭맞춤, 2p양면, 다크, 목차, 썸네일, 이동, 강조, 연필, 교정, 텍스트 추가, 검색, 이전/다음 페이지)를 원클릭 버튼으로 제공합니다.
* 마우스 오버(Hover) 하이라이트 및 현재 활성화된 보기 모드/주석 도구의 상태 표시를 지원합니다.

### 3. 하단 상태 표시줄 (Interactive Status Bar)
* **좌측:** 현재 페이지의 물리적 치수(cm 및 pt 단위)와 실시간 작업 상태 안내 메시지를 표시합니다.
* **중앙:** 처음(⏮) / 이전(◀) / 페이지 번호 점프 / 다음(▶) / 끝(⏭) 네비게이션 컨트롤을 클릭하여 이동할 수 있습니다.
* **우측:** 단면·양면 전환, 축소(-)/배율 초기화(100%)/확대(+), 전체 화면(⛶) 전환 버튼을 제공합니다.

### 4. 상단 10대 네이티브 메뉴바
* **[파일(&F)]** 빈 PDF 생성(A4), 클립보드에서 PDF 생성, 열기(O), 저장(Ctrl+S), 다른 버전 저장(PDF 1.4 / 1.7), 인쇄(Ctrl+P), 파일 속성(I)
* **[편집(&E)]** 본문 텍스트 객체 추가, 워터마크(기밀 / SAMPLE / 사용자 지정), 배경 색상(크림 / 민트), 머리글 & 바닥글, 페이지 번호, 베이츠 번호(Bates #000001)
* **[주석(&A)]** 강조(형광펜), 영역 강조, 밑줄(Ctrl+U), 취소선(Ctrl+Q), 연필, 지우개, 도형(직사각형 / 직선), 노트, 스탬프(APPROVED / DRAFT), 거리(cm/mm) 및 영역(sq cm) 측정
* **[변환(&C)]** 이미지(.bmp), 텍스트(.txt), 웹 문서(.html), Word 호환(.rtf), Excel 호환(.csv) 변환
* **[보기(&V)]** 확대/축소, 실제 크기, 창 맞추기(0), 너비 맞추기(W), 1p 단면 / 2p 양면(D) / 별도 표지, 회전(R), 눈금자(Ruler) 및 격자(Grid), 북마크(B)·썸네일 탭 전환 및 자동 북마크, 전체 화면(F11)
* **[구성(&P)]** 빈 페이지 삽입, 다른 PDF에서 페이지 삽입, 현재 페이지 삭제, 페이지 추출/분할 저장, 여백 자르기(CropBox), 페이지 자체 회전
* **[도구(&T)]** 문서 전체 검색(F), 페이지 이동(G), PDF 병합, PDF 비교(VS), 평면화(Flatten), 표 인식(CSV 복사), 화면 스크린샷 캡처(Ctrl+F1)
* **[양식(&M)]** 텍스트 필드 추가, 인터랙티브 체크 박스 추가, 양식 인식, 양식 데이터 CSV 추출
* **[보안(&S)]** 교정 표시 도구(검은색 마스킹), 검색 & 교정(키워드 일괄 마스킹), 숨겨진 데이터 정리, 디지털 서명 스탬프 삽입
* **[기타(&O)]** 야간 다크 모드(V), 배경 테마 색상(라이트 / 다크 / 클래식), 전체 도움말(H / F1)
