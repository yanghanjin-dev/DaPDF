# DaPDF v0.1.0 — 2026-11-16

Windows x64 프리뷰 배포입니다.

## 변경 사항

- 툴바·상태바, 목차·캐싱된 썸네일, 내부·외부 링크 탐색.
- 드래그 텍스트 선택, 부분 복사, 반투명 선택 표시와 더블 버퍼링.
- 우클릭 복사·강조·검색 메뉴.
- MinGW 호환 GDI+ 동적 로딩.
- PDF 열기·저장 실패를 표시하고, 저장 실패 시 원본 바이트로 조용히 대체하던 동작 제거.
- PDF 1.4·1.7 저장 메뉴를 연결하고 실제 버전을 전달하도록 수정.
- 인쇄 대화상자를 닫았을 때 출력 성공으로 오인시키던 표시 수정.
- 버전 검사·회귀 테스트·전체 PDFium 서드파티 라이선스·SHA256을 포함한 로컬 배포 스크립트.

## 검증

`cargo test --offline`의 단일 PDFium 통합 회귀 테스트 통과:

- 한글 파일 경로의 2페이지 PDF 로딩 및 텍스트 추출.
- 키워드 검색과 부분 텍스트 선택.
- 단면·양면·90도 회전 렌더링 및 썸네일 캐시.
- 텍스트 삽입과 빈 페이지 추가 후 PDF 1.4·1.7 저장, 헤더 확인, 다시 열어 페이지 수·추가 텍스트 확인.
- 문서 없는 저장, 잘못된 저장 경로 및 열기 실패의 오류 반환과 기존 문서 상태 유지.

실제 창은 초기 실행과 파일 열기 대화상자 표시까지 확인했습니다. 대화상자의 자동 입력·포커스 제어가 정상적으로 되지 않아 GUI를 통한 전체 열기·검색·드래그·저장 순서는 완료하지 못했습니다. 클립보드·외부 링크 실행·인쇄·모든 주석 및 양식의 GUI 검증은 미완료입니다.

릴리스 빌드 및 패키지 무결성 검증 결과는 `validation-v0.1.0.md`에 기록합니다.

## 알려진 제한

화면 주석·양식·워터마크는 일반 저장으로 보존되지 않습니다. 평면화 지원은 현재 페이지의 일부 항목에 한정되며 반복 실행 시 중복될 수 있습니다. 검은 사각형은 원문 삭제가 아니며 서명 이미지는 인증서 기반 서명이 아닙니다. 실제 인쇄 전송·OCR·표준 AcroForm 편집·편집 취소·미저장 경고는 미지원입니다. 자세한 범위는 README를 확인하세요.
