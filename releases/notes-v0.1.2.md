# DaPDF v0.1.2 — 2026-11-16

Windows x64 실행 버전입니다.

## 변경 사항

- 앱의 기본 도구를 ‘선택’으로 변경했습니다.
- 문서를 불러올 때마다 ‘선택’ 도구로 전환합니다. ‘이동’이나 다른 편집 도구를 사용하다가 새 문서를 열어도 텍스트 선택을 바로 사용할 수 있습니다.

## 실행

- 설치형: `DaPDF-v0.1.2-win-x64-setup.exe` 실행. 설치·제거에는 관리자 권한이 필요합니다.
- 포터블: `DaPDF-v0.1.2-win-x64.zip`을 풀고 `DaPDF.exe` 실행. PDFium DLL과 라이선스 파일을 함께 유지하세요.
- 각 파일의 SHA256 검증 파일을 제공합니다. 배포 파일은 코드 서명되지 않았습니다.

## 검증 및 제한

회귀 테스트 3개, 최적화 빌드 및 패키지 SHA256 검증을 통과했습니다. 전체 GUI·실제 인쇄·OCR·관리자 설치/제거의 수동 검증은 이번 배포에서 수행하지 않았습니다. 기존 기능과 제한은 v0.1.1 및 README를 확인하세요.
