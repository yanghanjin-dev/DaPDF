# DaPDF v0.1.3 — 2026-11-20

Windows x64 실행 버전입니다.

## 변경 사항

- 앱 시작 및 문서 열기 시 왼쪽 썸네일 패널을 기본 표시합니다.
- 목차 버튼·탭·자동 전환 및 목차 생성 UI를 비활성화했습니다.
- 썸네일 오른쪽에 검색 탭을 추가했습니다. 검색어 입력, 현재 페이지의 결과 건수 확인, 문서 전체 이전·다음 결과 이동을 지원합니다.
- F 또는 Ctrl+F로 검색 탭을 열고 F3·Shift+F3으로 결과를 이동할 수 있습니다.
- 문서 열기 시 기본 도구는 기존과 같이 ‘선택’입니다.

## 실행

- 설치형: `DaPDF-v0.1.3-win-x64-setup.exe` 실행. 설치·제거에는 관리자 권한이 필요합니다.
- 포터블: `DaPDF-v0.1.3-win-x64.zip`을 풀고 `DaPDF.exe` 실행. PDFium DLL과 라이선스 파일을 함께 유지하세요.
- 각 파일의 SHA256 검증 파일을 제공합니다. 배포 파일은 코드 서명되지 않았습니다.

## 검증 및 제한

회귀 테스트 3개, 최적화 빌드 및 패키지 SHA256 검증을 통과했습니다. 기본 썸네일 표시와 문서 열기 시 패널 초기화 검증을 포함합니다. 전체 GUI·실제 인쇄·OCR·관리자 설치/제거의 수동 검증은 이번 배포에서 수행하지 않았습니다. 기존 기능과 제한은 README를 확인하세요.
