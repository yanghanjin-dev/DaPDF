# DaPDF v0.1.6 — 2026-11-20

Windows x64 실행 버전입니다.

## 변경 사항

- 한글 조합 중인 글자를 검색 입력란에 즉시 표시하도록 Windows IME 처리를 추가했습니다. 확정된 글자의 중복 입력을 방지하고 후보 창을 검색 입력란 근처에 배치합니다.
- 입력 중 자동 검색을 제거했습니다. 검색어 입력 후 Enter를 누르면 문서 전체 검색을 시작합니다.
- 같은 검색어에서 Enter를 다시 누를 때마다 다음 검색 결과로 이동합니다. 마지막 결과 다음에는 첫 결과로 돌아갑니다.
- 문서 전체 총 검색 건수와 현재 결과 순서를 표시합니다.
- 검색어를 수정하면 Enter로 새 검색을 시작합니다. F3·Shift+F3과 이전·다음 버튼도 계속 사용할 수 있습니다.

## 실행

- 설치형: `DaPDF-v0.1.6-win-x64-setup.exe` 실행. 설치·제거에는 관리자 권한이 필요합니다.
- 포터블: `DaPDF-v0.1.6-win-x64.zip`을 풀고 `DaPDF.exe` 실행. PDFium DLL과 라이선스 파일을 함께 유지하세요.
- SHA256 검증 파일을 함께 제공합니다. 배포 파일은 코드 서명되지 않았습니다.

## 검증 및 제한

회귀 테스트 4개, 최적화 빌드 및 패키지 SHA256 검증을 통과했습니다. 한글 조합·확정·취소·중복 방지의 상태 처리, 2페이지 전체 검색 건수와 결과 없음 상태를 검증했습니다. 실제 Windows 한글 IME 조작과 전체 GUI·인쇄·OCR·관리자 설치/제거의 수동 검증은 이번 배포에서 수행하지 않았습니다. 기존 기능과 제한은 README를 확인하세요.
