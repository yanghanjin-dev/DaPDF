# DaPDF v0.1.1 — 2026-11-16

현재 소스를 빌드한 Windows x64 실행 버전입니다.

## 다운로드 및 실행

- 설치형: `DaPDF-v0.1.1-win-x64-setup.exe` 실행. 설치·제거 시 관리자 권한이 필요합니다.
- 포터블: `DaPDF-v0.1.1-win-x64.zip`을 풀고 `DaPDF.exe` 실행. pdfium.dll과 라이선스 폴더를 함께 유지하세요.
- 각 파일의 SHA256 검증 파일을 제공합니다. 코드 서명되지 않은 배포 파일입니다.

## 변경 사항

- Windows 설치·제거 프로그램, 종이비행기 아이콘, DPI와 창 너비에 대응하는 도구 모음·상태바.
- 강조·영역 강조·밑줄·취소선·연필의 PDF 주석 저장 및 재편집, 반복 저장 시 중복 방지.
- 편집 취소·다시 실행, 미저장 변경 확인, 파일 저장의 원자적 교체.
- 페이지 범위 추출·분할·순서 변경.
- Windows 인쇄 작업 전송, Windows OCR 및 텍스트 중심 DOCX 내보내기.

## 검증 및 제한

- `cargo test --offline`: 회귀 테스트 3개 통과. PDF 열기·렌더·검색·저장·주석 재로딩·편집 이력·페이지 작업·DOCX 생성과 도구 모음·상태바 배치를 확인했습니다.
- 최적화 빌드, 설치 EXE·포터블 ZIP 생성 및 SHA256 검증.
- 전체 GUI 시나리오, 실제 프린터 출력, OCR 언어별 결과, 실제 UAC/Program Files 설치·제거는 이번 배포에서 수동 검증하지 않았습니다.
- OCR에는 Windows OCR 언어 팩이 필요하며 DOCX는 원본 레이아웃을 보존하지 않습니다.
- 자체 양식·서명 이미지 등 일부 오버레이와 워터마크·배경색은 일반 PDF 저장으로 보존되지 않습니다. 평면화는 일부 항목만 지원하며 반복 시 중복될 수 있습니다.
- 검은 마스킹은 원문 삭제가 아니며, 서명 이미지는 인증서 기반 디지털 서명이 아닙니다. 암호 입력·표준 AcroForm 편집은 지원하지 않습니다.
- 편집 전에 원본 사본을 보관하세요. 검증 기록: `releases/validation-v0.1.1.md`.
