# DaPDF v0.1.8 — 2026-11-20

Windows x64 실행 버전입니다.

## 변경 사항

- 편집 메뉴의 ‘사용자 지정 워터마크 입력’을 별도 팝업창으로 변경했습니다.
- Windows 기본 입력란으로 한글 입력·붙여넣기와 기존 문구 수정을 지원합니다.
- 적용·취소 버튼을 제공합니다. 취소하거나 창을 닫으면 기존 워터마크를 유지합니다.
- 빈 문구 적용 시 입력 안내를 표시합니다.
- 워터마크가 화면 표시용이며 일반 PDF 저장에는 포함되지 않는다는 안내를 팝업에 표시합니다.

## 실행

- 설치형: `DaPDF-v0.1.8-win-x64-setup.exe` 실행. 설치·제거에는 관리자 권한이 필요합니다.
- 포터블: `DaPDF-v0.1.8-win-x64.zip`을 풀고 `DaPDF.exe` 실행. PDFium DLL과 라이선스 파일을 함께 유지하세요.
- SHA256 검증 파일을 함께 제공합니다. 배포 파일은 코드 서명되지 않았습니다.

## 검증 및 제한

기존 회귀 테스트 5개, 최적화 빌드 및 패키지 SHA256 검증을 통과했습니다. 워터마크 팝업의 실제 GUI 조작과 한글 입력, 인쇄·OCR·관리자 설치/제거의 수동 검증은 이번 배포에서 수행하지 않았습니다. 기존 기능과 제한은 README를 확인하세요.
