# v0.1.0 검증 기록

검증일: 2026-11-16 (Asia/Seoul)

## 통과

- `cargo test --offline`: PDFium 통합 회귀 테스트 1개 통과. 실행 전 `vendor/bin`을 프로세스 PATH에 추가.
- 한글 경로 PDF 로드, 2페이지 확인, 텍스트 추출, 검색, 부분 선택.
- 단면·양면·회전 렌더 버퍼 및 썸네일 캐시 생성.
- 실제 텍스트 객체 삽입·페이지 추가 후 PDF 1.4와 1.7 저장 및 재로딩: 버전 헤더, 3페이지, 삽입 텍스트 확인.
- 문서 없는 저장과 디렉터리 대상 저장·열기 실패 시 오류 반환 및 기존 문서 상태 유지.
- `cargo build --release --offline`: Windows x64 최적화 빌드 성공.
- `release.ps1`: 버전 일치 검사, 회귀 테스트, 빌드, ZIP 및 SHA256 생성 성공.
- ZIP을 별도 검증 디렉터리에 풀어 실행 파일·PDFium DLL·README·VERSION의 원본과 SHA256 일치 확인.
- PDFium 서드파티 라이선스 18개 포함 및 ZIP SHA256 일치 확인.
- `git diff --check`: 오류 없음.

## GUI 확인 범위

초기 앱 실행과 파일 열기 대화상자 표시를 확인했습니다. 자동 입력·포커스 제어가 정상적으로 되지 않아 GUI 전체 시나리오는 완료하지 못했습니다. 테스트용 앱에는 파일을 편집하거나 저장하지 않았습니다.

검색·부분 선택·편집·저장 검증은 GUI가 아닌 실제 AppState/PDFium 경로로 실행했습니다. 실제 마우스 드래그, 클립보드, 링크 실행, 서명 이미지, 모든 양식 조작, 복잡한 대용량·암호 PDF는 별도 수동 검증이 필요합니다.

## 수정 사항

저장 오류를 성공으로 표시하던 처리와 PDFium 저장 실패 시 원본을 복사하여 성공 처리하던 경로를 제거했습니다. PDF 버전 지정 저장 메뉴와 인수를 연결했습니다. 인쇄 전송 미구현 상태를 UI 및 문서에 반영했습니다.

## 배포 결과

`releases/DaPDF-v0.1.0-win-x64.zip`과 같은 경로의 `.zip.sha256` 파일을 생성했습니다. 이 패키지는 프리뷰입니다. GitHub 업로드·태그·커밋은 수행하지 않았습니다. 기존 v0.0.2 미추적 폴더는 유지했습니다.

현재 환경은 서명되지 않은 PowerShell 파일의 직접 실행을 제한하여, 패키징에는 해당 자식 프로세스에만 적용되는 `powershell -NoProfile -ExecutionPolicy Bypass -File .\release.ps1`을 사용했습니다. 시스템 실행 정책은 변경하지 않았습니다.
