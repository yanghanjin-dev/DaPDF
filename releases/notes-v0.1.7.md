# DaPDF v0.1.7 — 2026-11-20

Windows x64 실행 버전입니다.

## 변경 사항

- 전체화면에서 상단 메뉴를 숨기고 일반 화면 복귀 시 복원합니다.
- 왼쪽 패널 너비에 맞춰 썸네일을 다시 렌더링하고 확대·축소합니다. 썸네일 행 높이·클릭 위치·스크롤 간격도 함께 조절됩니다.
- 선택한 페이지의 썸네일에 빨간 테두리를 표시합니다.
- 현재 화면에서 보이는 문서 영역을 해당 썸네일에 파란 사각형으로 표시합니다. 확대·이동·스크롤 및 양면 보기의 페이지 배치를 기준으로 계산합니다.

## 실행

- 설치형: `DaPDF-v0.1.7-win-x64-setup.exe` 실행. 설치·제거에는 관리자 권한이 필요합니다.
- 포터블: `DaPDF-v0.1.7-win-x64.zip`을 풀고 `DaPDF.exe` 실행. PDFium DLL과 라이선스 파일을 함께 유지하세요.
- SHA256 검증 파일을 함께 제공합니다. 배포 파일은 코드 서명되지 않았습니다.

## 검증 및 제한

회귀 테스트 5개, 최적화 빌드 및 패키지 SHA256 검증을 통과했습니다. 썸네일 확대·축소와 화면 표시 영역의 좌표 변환 검증을 포함합니다. 실제 전체화면 전환과 테두리 표시를 포함한 전체 GUI·인쇄·OCR·관리자 설치/제거의 수동 검증은 이번 배포에서 수행하지 않았습니다. 기존 기능과 제한은 README를 확인하세요.
