DaPDF의 첫 번째 Windows x64 릴리즈입니다.

- PDF 열기 및 드래그 앤 드롭, 한글 경로 지원
- 여러 페이지 연속 스크롤 및 보이는 페이지 렌더링 캐시
- 페이지 이동, 확대/축소, 창 너비 맞춤, 90도 회전

사용 방법: DaPDF-v0.0.1-windows-x64.zip을 내려받아 압축을 풀고 DaPDF.exe를 실행하세요. pdfium.dll과 라이선스 파일을 함께 유지하세요.

읽기 전용 뷰어이며 암호 입력, 검색·선택, 인쇄, 편집은 지원하지 않습니다.

검증: GCC C11 빌드(-Wall -Wextra -Werror) 및 PDF 로딩·렌더링·스크롤·페이지 이동·확대/축소·회전·메모리 정리 통합 테스트 통과.
