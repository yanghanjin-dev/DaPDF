# DaPDF v0.1.4 — 2026-11-20

Windows x64 실행 버전입니다.

## 변경 사항

- 왼쪽 썸네일·검색 패널의 오른쪽 경계를 드래그해 너비를 조절할 수 있습니다.
- 조절한 너비에 맞춰 문서 영역, 썸네일 위치, 검색 입력란 및 닫기 버튼이 배치됩니다.
- 검색 입력란에 포커스가 있으면 ‘검색어 입력...’ 안내 문구가 사라지고 세로 입력 커서가 깜빡입니다.
- 앱이 포커스를 잃으면 입력 커서 표시를 멈춥니다.
- 검색 패널을 좁혔을 때 안내 문구가 본문 영역으로 넘치지 않도록 처리했습니다.

## 실행

- 설치형: `DaPDF-v0.1.4-win-x64-setup.exe` 실행. 설치·제거에는 관리자 권한이 필요합니다.
- 포터블: `DaPDF-v0.1.4-win-x64.zip`을 풀고 `DaPDF.exe` 실행. PDFium DLL과 라이선스 파일을 함께 유지하세요.
- SHA256 검증 파일을 함께 제공합니다. 배포 파일은 코드 서명되지 않았습니다.

## 검증 및 제한

회귀 테스트 3개, 최적화 빌드 및 패키지 SHA256 검증을 통과했습니다. 이번 변경의 실제 마우스 드래그·커서 깜빡임을 포함한 전체 GUI 수동 검증은 수행하지 않았습니다. 실제 인쇄·OCR·관리자 설치/제거도 이번 배포의 수동 검증 범위에 포함되지 않습니다. 기존 기능과 제한은 README를 확인하세요.
