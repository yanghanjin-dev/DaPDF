# DaPDF v0.1.5 — 2026-11-20

Windows x64 실행 버전입니다.

## 수정 사항

- 검색 탭을 열거나 빈 검색 입력란을 표시할 때 프로그램이 접근 위반(0xc0000005)으로 종료되는 문제를 수정했습니다.
- 빈 검색어의 그리기 버퍼를 NUL 종료된 유효한 UTF-16 버퍼로 전달하고, 빈 문자열은 글자 폭 측정을 생략하도록 수정했습니다.
- 빈 검색어·한글·영문·긴 검색어, 패널 너비 200·280·640, 입력 포커스와 커서 표시 상태를 조합한 검색창 그리기 회귀 검증을 추가했습니다.

## 실행

- 설치형: `DaPDF-v0.1.5-win-x64-setup.exe` 실행. 설치·제거에는 관리자 권한이 필요합니다.
- 포터블: `DaPDF-v0.1.5-win-x64.zip`을 풀고 `DaPDF.exe` 실행. PDFium DLL과 라이선스 파일을 함께 유지하세요.
- SHA256 검증 파일을 함께 제공합니다. 배포 파일은 코드 서명되지 않았습니다.

## 검증 및 제한

수정 전 검색창 그리기 테스트에서 접근 위반 종료를 재현했고, 수정 후 같은 경로가 통과했습니다. 회귀 테스트 3개, 최적화 빌드 및 패키지 SHA256 검증을 통과했습니다. 전체 GUI·실제 인쇄·OCR·관리자 설치/제거의 수동 검증은 이번 배포에서 수행하지 않았습니다. 기존 기능과 제한은 README를 확인하세요.
